# 第 1 周小工具：日志统计 CLI

对照这份文件自己实现。先**不要打开**同目录下的 `logstat.py`（那是写完后的对照答案）。

你的代码建议写成 `my_logstat.py`，样例日志直接用 `sample/` 里的两个文件。

---

## 1. 要做什么

命令行读取一份日志，统计：

- HTTP 状态码各出现多少次
- 延迟的 p50、p95、最大值
- 最慢的 N 条请求

只允许使用 **Python 标准库**，不要 `pip install` 任何包。

对应学习点：`pathlib`、`dict`、类型标注、`argparse`。能跑即可，生成器、推导式有余力再写。

---

## 2. 命令行

```text
python my_logstat.py <logfile> [--path 子串] [--errors] [--slow N]
```


| 参数         | 必填  | 含义                  |
| ---------- | --- | ------------------- |
| `logfile`  | 是   | 日志文件路径              |
| `--path`   | 否   | 只保留 `path` 包含该子串的请求 |
| `--errors` | 否   | 只保留 `status >= 400` |
| `--slow N` | 否   | 打印最慢的 N 条，默认 `5`    |


出错时把原因打到 **stderr**，进程退出码为 **1**：

- 文件不存在
- `--slow` 小于 1

成功则退出码 **0**。

---



## 3. 两种输入格式（自动识别）

读文件前几行**非空**内容：

- 第一个非空行去掉左侧空格后以 `{` 开头 → 整份文件按 **JSONL** 解析
- 否则 → 整份文件按 **访问日志** 解析

某一行解析失败：跳过，不要让程序崩溃。空行也算跳过。

### 3.1 访问日志

一行一条，末尾是**秒**为单位的耗时：

```text
10.0.0.8 - - [20/Sep/2026:12:00:03 +0800] "POST /chat HTTP/1.1" 200 880 0.210
```

需要取出：

- `method`：`POST`
- `path`：`/chat`
- `status`：`200`
- 耗时秒：`0.210` → 转成毫秒时 **乘 1000**
- `request_id`：这种格式没有，填 `"-"`

样例：`sample/access.log`  
其中有一行垃圾 `this line is garbage and should be skipped`，必须跳过。

### 3.2 JSONL 应用日志

一行一个 JSON 对象：

```json
{"request_id": "req-002", "method": "POST", "path": "/chat", "status": 200, "latency_ms": 210.0}
```

必须有字段：`method`、`path`、`status`、`latency_ms`。缺任何一个，或根本不是 JSON → 跳过。  
`request_id` 没有就填 `"-"`。这里的延迟已经是毫秒，不要再乘 1000。

样例：`sample/app.jsonl`  
最后一行 `{"not": "a valid request record"}` 必须跳过。

---



## 4. 内部统一成同一种记录

两种格式解析完后，每条记录都是：


| 字段           | 类型  | 说明               |
| ------------ | --- | ---------------- |
| `method`     | 字符串 | `GET` / `POST` 等 |
| `path`       | 字符串 | 如 `/chat`        |
| `status`     | 整数  | HTTP 状态码         |
| `latency_ms` | 浮点数 | 毫秒               |
| `request_id` | 字符串 | 没有则为 `"-"`       |


用 `dataclass` 或普通 class 都可以。

---



## 5. 统计规则

先按 `--path`、`--errors` 过滤，再对**过滤后的列表**做统计。

### 状态码

按状态码计数，输出时按状态码数字从小到大排。

### 分位数

对延迟列表排序后按下标取值（不要自己发明更复杂的插值）：

```text
index = round( (长度 - 1) * 比例 )
```

再把 `index` 限制在 `0 ~ 长度-1`。

- p50：比例 `0.50`
- p95：比例 `0.95`
- max：列表最大值

过滤后一条都没有：打印 `no matching records`，不要除零、不要取空列表的 max。

### 最慢请求

按 `latency_ms` 从大到小排序，取前 N 条（N 来自 `--slow`）。

---



## 6. 输出格式

字段要有，对齐不必和下面逐字符相同。

```text
file: sample\access.log
lines: 12  parsed: 11  skipped: 1
records: 11

status
  200  8
  404  1
  429  1
  500  1

latency_ms
  p50  95.0
  p95  2800.0
  max  2800.0

slowest_5
  2800.0  500  GET     /query  -
  1250.0  200  POST    /ingest  -
   430.0  200  POST    /chat  -
   210.0  200  POST    /chat  -
   180.0  200  POST    /chat  -
```

含义：

- `lines`：文件总行数（含空行、垃圾行）
- `parsed`：两种格式里成功解析出的条数（过滤前）
- `skipped`：总行数减去成功解析条数
- `records`：过滤之后用于统计的条数

访问日志没有 `request_id`，最慢列表最后一列是 `-`。JSONL 则打印真正的 id。

## 8. 验收命令

在 `week1_logstat` 目录下：

```powershell
python my_logstat.py sample\access.log
python my_logstat.py sample\app.jsonl --slow 3
python my_logstat.py sample\app.jsonl --path /chat --errors
```



### 自测期望（方便你对答案，不必格式逐字相同）

**命令 1** `sample\access.log`

- `lines 12`，`parsed 11`，`skipped 1`，`records 11`
- 状态码：`200×8`、`404×1`、`429×1`、`500×1`
- p50 ≈ `95`，p95 ≈ `2800`，max ≈ `2800`（毫秒）
- 最慢第一条是 `/query`、状态 `500`、约 `2800` ms

**命令 2** `sample\app.jsonl --slow 3`

- `lines 10`，`parsed 9`，`skipped 1`
- 最慢 3 条应是：`/query` 2800ms（req-006）、`/ingest` 1250.2ms（req-004）、`/chat` 430.7ms（req-009）

**命令 3** `--path /chat --errors`

- 只保留 path 含 `/chat` **且** status ≥ 400
- 应只剩 1 条：`429`、`POST /chat`、约 `21.3` ms、`req-007`

再手测两个错误路径：

```powershell

```

## 10. 本周会用到的标准库（用到再查）


| 你要做的事      | 用什么                                                             |
| ---------- | --------------------------------------------------------------- |
| 命令行参数      | `argparse`                                                      |
| 文件路径、读文本   | `pathlib.Path` → `read_text(encoding="utf-8")` → `splitlines()` |
| 访问日志拆字段    | `re.compile` + `match`，或先 `split()` 能跑也行                        |
| JSON 一行    | `json.loads(line)`，失败捕获 `json.JSONDecodeError`                  |
| 结构体        | `@dataclass`                                                    |
| 计数         | `dict`，`d[k] = d.get(k, 0) + 1`                                 |
| 排序         | `sorted(列表, key=..., reverse=True)`                             |
| 退出码 / 错误输出 | `sys.exit(1)`，`print(..., file=sys.stderr)`                     |
